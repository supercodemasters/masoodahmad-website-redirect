Services

Measure what happens on Google

Without measurement there is no way to know if any work had an effect.

Google Search Console and Bing Webmaster Tools show which searches show your website, how often it is clicked and which errors the search engines find. I set up the tools, submit sitemaps and follow up regularly.

What is included

  • Domain verification in Google Search Console
  • Import into Bing Webmaster Tools
  • Sitemap and IndexNow on every publish
  • Follow-up of keywords, clicks and errors

Good to know

  • Verification is done via DNS, without touching your email
  • You own the accounts; I get access
  • Reports can be sent automatically every month

Frequently asked questions

What is IndexNow?

A way to tell Bing and other search engines immediately when a page is new or changed.

Do we need Google Analytics too?

Not necessarily. Search Console shows the searches; visitor statistics can be measured in other ways.
